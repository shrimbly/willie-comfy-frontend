<objective>
Add a right-click context menu for sprites on the Moshpit canvas using Reka UI's `ContextMenu*` primitives. Acts on the current selection if the right-clicked sprite belongs to it, otherwise on just the right-clicked sprite. Menu items: Pin here / Unpin, Download, Select similar (same workflow), Reset all pins.

Purpose: Give users curation actions on sprites without leaving the canvas. This is the first sprite-control UI to mount on `moshpitOverrideStore` (laid down by 260423-j4f) and `moshpitSpriteDrag` (laid down by 260423-kdv), and it paves the wiring site for the upcoming floating action bar.

Output:

- `MoshpitSpriteContextMenu.vue` — controlled Reka context menu
- `SpriteHitTester.getSpriteWorldPos(hash)` — foundation API used by Pin here
- MoshpitView wiring (contextmenu listener + menu mount)
- i18n strings under `moshpit.contextMenu.*`
- Behavioural unit tests
  </objective>

         ```ts
         function onContextMenu(e: MouseEvent) {
           const el = containerEl.value
           const vp = viewportRef.value
           const hitTester = spriteHitTestRef.value
           if (!el || !vp || !hitTester) return
           const bounds = el.getBoundingClientRect()
           const world = vp.toWorld(e.clientX - bounds.left, e.clientY - bounds.top)
           const hit = hitTester.hitTestPoint(world.x, world.y)
           if (hit === null) return   // let browser show native menu on empty canvas
           e.preventDefault()
           contextMenuRef.value?.open(e.clientX, e.clientY, hit)
         }
         ```
