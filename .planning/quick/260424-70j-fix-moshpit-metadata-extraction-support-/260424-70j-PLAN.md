<objective>
Fix two concrete metadata extraction gaps in `paramNormalize.ts` that cause model and seed to be `undefined` for the majority of real Moshpit assets:

1. **UNETLoader** (used by FLUX, Z-Image, WAN, SD3 workflows — 43/80 sampled PNGs) is not in `CHECKPOINT_CLASS_TYPES`, and its input key is `unet_name` rather than `ckpt_name`. Result: `params.model === undefined` for every UNETLoader asset.
2. **KSamplerAdvanced** uses `noise_seed` instead of `seed` (86 occurrences in the real sample). Result: `params.seed === undefined` for every KSamplerAdvanced asset.

Purpose: Restore correct model + seed extraction so grouping (model axis), metadata peek, and seed filtering work for the real prosumer workflows users run. Without this fix the canvas silently degrades to "(other)" buckets and missing seed chips.

Output: Updated `paramNormalize.ts` + new unit tests covering both paths. No changes to extraction flow beyond these two reads.
</objective>
