# Summary — Quick Task 260424-70j

Fix for two concrete gaps in PNG metadata extraction that caused the Moshpit
asset metadata panel to show empty `model` and `seed` fields for the majority
of real user assets. Diagnosed against 80 recent PNGs in the local ComfyUI
output directory: 43/80 used `UNETLoader` (FLUX/Z-Image/WAN/SD3 family),
86 occurrences of `KSamplerAdvanced` in the sample.

## Changes

### `src/platform/moshpit/services/paramNormalize.ts`

- Renamed `CHECKPOINT_CLASS_TYPES` → `MODEL_LOADER_CLASS_TYPES` and added
  `'UNETLoader'` to the set. The set now covers `CheckpointLoaderSimple`,
  `CheckpointLoader`, and `UNETLoader`.
- Model extraction now reads `ckpt_name ?? unet_name` so both loader shapes
  resolve to a string.
- Sampler seed extraction now reads `seed ?? noise_seed` so
  `KSamplerAdvanced` (which uses `noise_seed`) resolves correctly. `KSampler`
  and `KSamplerAdvanced` behaviour both covered.
- No other extraction logic touched — cfg, steps, sampler, scheduler, prompts,
  loras, latent, fingerprint, and saveNodeIdentity are byte-identical.

### `src/platform/moshpit/services/paramNormalize.test.ts`

- Added `describe('UNETLoader model extraction')` — 4 tests (extracts
  `unet_name`, empty-string handling, prefers `ckpt_name` when both present,
  falls back to `unet_name` when `ckpt_name` absent).
- Added `describe('KSamplerAdvanced seed extraction')` — 4 tests (extracts
  `noise_seed`, non-numeric `noise_seed`, KSampler `seed` preferred,
  KSamplerAdvanced with only `noise_seed`).
