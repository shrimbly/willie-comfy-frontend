<objective>
Enforce the grouping contract: when the user changes `activeGroupings` (via
`toggleGrouping` in the settings panel), wipe all sprite-layer overrides (both
pins and scales) so clusters reflow cleanly. Sort-mode and grid-spacing changes
must NOT clear overrides.

Purpose: Today pinned sprites keep their absolute world positions across
regroup because `resolveSlot` applies overrides last (override-wins). User
intent when toggling a grouping axis is "I want to see the new grouping" — the
pins fight that. Clearing on grouping change makes the regroup authoritative.

Output: One watch in `MoshpitView.vue` plus a Vitest regression test.
</objective>
