<objective>
Ship the worker-safe, Zod-validated `paramNormalize.ts` leaf module that turns a ComfyUI PNG `prompt` chunk into a typed `NormalizedParams` record. This is the foundation of Phase 3 — every filter chip, sort axis, and workflow-picker entry reads from this shape.

Purpose: Establish per-D-05 normalized parameter extraction that runs in the Web Worker at parse time (D-01). Downstream plans (worker extension, filterMath, sortMath, workflow picker) depend on this module's shape and Zod schema. TDD-first because the shape is a contract — writing the test first locks it in.

**Shape deviation (see deviation_note frontmatter):** D-05 locks the 12 core parameter fields. This plan adds two derived identification fields on top: `workflowFingerprint` (always a string — may be empty) and `workflowFilename` (string | null — heuristic from PNG filename stem, used as the picker's human-readable display name per OQ-3 resolution). Together they let the workflow picker show a recognizable label ("my_cfg_sweep (23 assets)" instead of "CLIPTextEncode|CheckpointLoaderSimple|KSampler (23 assets)"). When `workflowFilename` is null the picker falls back to `'unnamed-' + workflowFingerprint`.

Output: A pure TypeScript module with an exported `normalizeParams(rawMeta, createdAtMs, sourceFilename?) → NormalizedParams` function, a Zod schema for validation, a standalone `extractWorkflowFilename(name) → string | null` helper, and a comprehensive test suite.
</objective>

Workflow filename heuristic (extractWorkflowFilename):
- Input: a string like "my_cfg_sweep_00042_.png" or "some/path/flow.png" or "" or null
- Strip any leading path components (keep only the final segment)
- Strip the file extension (last `.png`, `.jpg`, `.jpeg`, `.webp`)
- Strip a trailing ComfyUI counter suffix of the form `_\d{4,6}_?$` or `_\d{4,6}$` (the `_NNNNN_` or `_NNNNN` pattern ComfyUI appends to generated PNGs)
- Trim remaining trailing underscores/whitespace
- If the remaining string is empty, return null
- Otherwise return the stem as a string

**`extractWorkflowFilename`** — reference implementation:

```typescript
const IMAGE_EXT_RE = /\.(png|jpe?g|webp)$/i
const COUNTER_SUFFIX_RE = /_\d{4,6}_?$/

export function extractWorkflowFilename(
  sourceFilename: string | null | undefined
): string | null {
  if (sourceFilename === null || sourceFilename === undefined) return null
  if (typeof sourceFilename !== 'string') return null
  // Strip path
  const lastSlash = Math.max(
    sourceFilename.lastIndexOf('/'),
    sourceFilename.lastIndexOf('\\')
  )
  const base = lastSlash >= 0 ? sourceFilename.slice(lastSlash + 1) : sourceFilename
  // Strip extension
  const noExt = base.replace(IMAGE_EXT_RE, '')
  // Strip ComfyUI counter suffix (_NNNNN_ or _NNNNN)
  const noCounter = noExt.replace(COUNTER_SUFFIX_RE, '')
  const trimmed = noCounter.replace(/[_\s]+$/, '').trim()
  return trimmed.length > 0 ? trimmed : null
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PNG-file → worker | Untrusted binary input; metadata strings extracted from tEXt chunks |
| PNG filename → filename heuristic | Untrusted string (from AssetItem.filename or src_url); regex-parsed only |
| worker → main-thread (IDB) | Structured-cloned payload; must not contain functions or DOM nodes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Tampering | `normalizeParams` JSON.parse | mitigate | `try/catch` wrapping `JSON.parse(rawMeta['prompt'])`; fall back to `emptyParams` per D-03; test case covers malformed JSON |
| T-03-01-02 | Tampering | Prototype pollution via parsed prompt graph | mitigate | Shallow type guard rejects non-plain objects; never spread parsed values into store state; narrow every `unknown` via typeof before use |
| T-03-01-03 | Information Disclosure | Prompt text content (user's prompts) | accept | Prompts are user-owned, local-only; no network egress introduced by this module |
| T-03-01-04 | Denial of Service | Very large prompt JSON (>10MB) causing worker hang | accept | ComfyUI PNG metadata is bounded by file size and worker has its own concurrency cap (4); pathological input is a pre-existing Phase 2 risk, not introduced here |
| T-03-01-05 | Tampering | Pathological filename triggers regex backtracking | mitigate | Regexes are anchored and non-backtracking (`/_\d{4,6}_?$/`, `/\.(png\|jpe?g\|webp)$/i`); worst case linear in filename length; filename input is bounded by filesystem limits |
</threat_model>
