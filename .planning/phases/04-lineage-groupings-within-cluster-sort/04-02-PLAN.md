```typescript
if (oldVersion < 3) {
  const store = tx.objectStore('assetMeta')
  let cursor = await store.openCursor()
  let skipped = 0
  while (cursor) {
    const rec = cursor.value
    // Re-derive saveNodeIdentity from stored rec.metadata. If rec.params is
    // already present (v2 records), spread-replace only that field. Otherwise
    // run the full normalizeParams (covers records written during migration
    // between the v2 and v3 upgrades).
    try {
      const fresh = normalizeParams(
        rec.metadata,
        rec.params?.timestamp ?? Date.now()
      )
      const nextParams = rec.params
        ? { ...rec.params, saveNodeIdentity: fresh.saveNodeIdentity }
        : fresh
      await cursor.update({ ...rec, params: nextParams })
    } catch (err) {
      skipped += 1
      console.error(
        '[moshpit] v2→v3 migration failed for record',
        rec.contentHash,
        err
      )
    }
    cursor = await cursor.continue()
  }
  if (skipped > 0) {
    console.warn(`[moshpit] v2→v3 migration skipped ${skipped} records`)
  }
}
```

| Boundary                                                   | Description                                                                                                                                                                                                                    |

| Stored IDB `assetMeta.metadata` → fresh `NormalizedParams` | The migration re-parses already-stored PNG metadata strings. This is the same boundary Phase 3's v1→v2 migration crosses. Raw metadata is user-generated content but already bounded by the asset pipeline's ingestion limits. |

## STRIDE Threat Register

| Threat ID  | Category               | Component                                                           | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                                                                      |
| ---------- | ---------------------- | ------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| T-04-02-01 | Denial of Service      | v2→v3 upgrade callback                                              | mitigate    | Per-record try/catch prevents a single malformed record from aborting the versionchange transaction (Pitfall 4). Cursor-based streaming keeps memory O(1) regardless of record count. Skip counter logged at the end for diagnosability.                                                                                             |
| T-04-02-02 | Tampering              | Malicious PNG metadata produces oversized `saveNodeIdentity` string | mitigate    | `saveNodeIdentity` is derived from `_meta.title` (arbitrary workflow author input) or `class_type` (ComfyUI node registry). Length is naturally bounded by the prompt graph JSON already persisted in `rec.metadata`. UI rendering in Plan 04 will truncate labels to ~28 chars (D-06) so a long string cannot overflow the overlay. |

Logging it aids diagnosability without leaking user prompts or workflow contents (those are NOT logged). Mirrors existing v1→v2 behaviour.                                                                                                                         |
